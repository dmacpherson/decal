# VPN module Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `vpn` module that installs and sets up any of Tailscale, NetBird, Proton VPN, WireGuard, OpenVPN and
OpenConnect (with tray icons and Tailscale's no-sudo control), stamps what a machine uses, and removes exactly what it
added.

**Architecture:** One module (`modules/vpn/`) whose `module.sh` loops over a fixed service list and calls each
service's `<name>_add/_remove/_status/_stamp` from a small file per service. Vendor package repos (Tailscale, NetBird,
Proton; and the existing Claude desktop repo) go through one new shared helper, `repo_add`/`repo_remove` in
`lib/backends/_shared.sh`, which pins signing keys by fingerprint and records what it wrote.

**Tech Stack:** Bash (modules, backends), Python 3 stdlib (`lib/profile.py`), the repo's own test harness
(`tests/lib.sh`: `stub`, `mod_run`, fake root).

**Spec:** `docs/design/2026-10-16-vpn-design.md`

## Global Constraints

- Platforms: Fedora Atomic (`fedora-atomic`), Fedora/RHEL (`fedora`), Debian/Ubuntu (`debian`), Arch (`arch`). Use
  backend functions (`pkg_install`, `pkg_remove`, `_pkg_present`, `_pkg_name`), never a package manager directly.
- System paths always through `sys_path`; root writes through `srun`/`swrite`; state in `$LS_STATE/vpn/` (root) and
  `$LS_USER_STATE/` (user). Never run anything as root that's per user (tray autostart).
- The profile only picks names from: `tailscale`, `netbird`, `protonvpn`, `wireguard`, `openvpn`, `openconnect`.
  Repo URLs, keys and fingerprints live in decal's code only.
- Signing keys: https only (`ls_fetch`), checked against a pinned fingerprint; exactly one primary key per file; fail
  closed ("nothing added") on a mismatch.
- Never removed: `/var/lib/tailscale`, `/var/lib/netbird`, Proton's sign-in, NetworkManager connections, a repo /
  service / tray entry / package that existed before decal.
- No secrets anywhere: no auth keys, no `.ovpn`, no WireGuard keys, no server URLs.
- Messages in plain words: what happened, what to do next. No tracebacks.
- Tests hermetic: no network, no real home, stub every outside command. Commit style:
  `area: what changed, plainly` (lowercase), then `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Before every commit: `bash tests/run.sh 2>&1 | grep failed | grep -v ' 0 failed'` prints nothing, and
  `shellcheck decal install.sh usb/start.sh tools/*.sh modules/vpn/*.sh lib/backends/*.sh` is clean.

## Rulings (decisions the spec didn't make; also recorded in the commits)

1. `repo_add` takes options (`repo_add NAME --key URL FPR [--key URL FPR]... [--apt LINE] [--dnf BASEURL]
   [--repo-gpgcheck]`, `KEYRING` in LINE stands for the key's path) instead of the spec's fixed positional list:
   NetBird needs a different key per package system and Proton one per Fedora release.
2. dnf key files are named by fingerprint (`/etc/pki/rpm-gpg/decal-NAME-FPR.asc`); a recorded repo whose file would
   now read differently (decal learnt a new key) is rewritten, the old key files removed. Proton's dnf repo lists the
   keys of the current Fedora release and every later one decal knows, so a Fedora upgrade decal knows about keeps
   working. Known limit (roadmap): upgrading to a Fedora release decal doesn't know a Proton key for yet fails on
   Proton's packages until `decal add vpn` runs with a newer decal.
3. A Fedora release decal has no Proton key for: Proton is skipped with a warning (not a failure); a key that doesn't
   match its fingerprint stops the module (fail closed).
4. Apt key files keep their format's extension (`.asc` armored, `.gpg` binary; apt requires it), so Tailscale's lands
   where Tailscale's own instructions put it.
5. An existing `NAME.list`, `NAME.sources` or `NAME.repo` decal didn't write (set up by hand, or by Proton's release
   package, which writes `protonvpn-stable.sources`) means "use as is": nothing written, nothing removed.
6. gpg missing on Debian: `repo_add` installs `gnupg` under the owner `repo-NAME`; `repo_remove` removes it again.
7. `tests/test_claude.sh` changes its fakes only (a `pub` line from the gpg stub, an armored fake key); every
   assertion stays.
8. NetBird's service: decal runs `netbird service install` + `start` only when it isn't enabled (Atomic after the
   reboot), and records it; NetBird's UI gets `~/.config/autostart/netbird-ui.desktop` from decal, recorded.
9. Service status words: `<name>_status` prints nothing when complete, `skipped: …` when it can't apply here (counts
   as done, so Arch isn't re-run forever), `not installed`, or what's missing.

```bash
# fake_key FILE FPR... : a key file (armored-looking) holding these primary keys; stub_gpg reads it like gpg would.
# fake_key -b FILE FPR... : the same without the armor (a binary key, e.g. Tailscale's for apt)
fake_key() {
  local armor=1; if [[ $1 == -b ]]; then armor=0; shift; fi
  local f=$1; shift
  { if (( armor )); then echo '-----BEGIN PGP PUBLIC KEY BLOCK-----'; fi
    printf 'PUB=%s\n' "$@"
    if (( armor )); then echo '-----END PGP PUBLIC KEY BLOCK-----'; fi; } > "$f"
}
# stub_gpg : gpg --show-keys --with-colons FILE lists FILE's fake_key primary keys (a pub line, then its fpr line)
stub_gpg() { stub gpg 'k="${*: -1}"; grep -o "PUB=[A-F0-9]*" "$k" | while read -r l; do echo "pub:-:255:22:0000000000000000:1::::::scESC:"; echo "fpr:::::::::${l#PUB=}:"; done'; }
```

```bash
# --- vendor package repositories (apt, dnf, rpm-ostree): keys pinned by fingerprint, recorded so remove takes exactly them
# _key_fpr FILE : the fingerprint of FILE's one primary key; fails on none or several (a second key would be trusted too)
_key_fpr() {
  gpg --batch --show-keys --with-colons "$1" 2>/dev/null \
    | awk -F: '/^pub:/ {n++; want=1; next} want && /^fpr:/ {fpr=$10; want=0} END {if (n != 1) exit 1; print fpr}'
}
_ARMOR='-----BEGIN PGP PUBLIC KEY BLOCK-----'
# repo_add NAME --key URL FPR [--key URL FPR]... [--apt LINE] [--dnf BASEURL] [--repo-gpgcheck]
#   apt: the (first) key to /usr/share/keyrings/NAME-archive-keyring.asc|.gpg (armored|binary: apt goes by the
#   extension), LINE to /etc/apt/sources.list.d/NAME.list (KEYRING in LINE stands for the key's path).
#   dnf, rpm-ostree: each key to /etc/pki/rpm-gpg/decal-NAME-FPR.asc, /etc/yum.repos.d/NAME.repo using only those
#   (gpgkey=file://: never fetched again from the internet). A changed key list rewrites a repo decal added.
# Each key must have its pinned fingerprint, or nothing is written. A NAME repository decal didn't add (by hand, or
# the vendor's own package) is used as is. Arch: nothing to do.
repo_add() {
  local name=$1 apt="" dnf="" rgc=0 urls=() fprs=(); shift
  while (( $# )); do
    case $1 in
      --key) urls+=("$2"); fprs+=("$3"); shift 3 ;;
      --apt) apt=$2; shift 2 ;;
      --dnf) dnf=$2; shift 2 ;;
      --repo-gpgcheck) rgc=1; shift ;;
      *) die "repo_add: unknown option $1" ;;
    esac
  done
  local rec="$LS_STATE/repos/$name" src kps=() body="" i
  case $PLATFORM in
    debian) [[ -n $apt ]] || return 0; src=/etc/apt/sources.list.d/$name.list ;;
    fedora|fedora-atomic) [[ -n $dnf ]] || return 0; src=/etc/yum.repos.d/$name.repo ;;
    *) return 0 ;;
  esac
  if [[ ! -e $rec ]] && [[ -e $(sys_path "$src") || -e $(sys_path "/etc/apt/sources.list.d/$name.sources") ]]; then
    info "using the $name package repository already set up on this system"; return 0
  fi
  if [[ $PLATFORM == debian ]]; then
    [[ ! -e $rec ]] || return 0
  else
    for i in "${!fprs[@]}"; do kps+=("/etc/pki/rpm-gpg/decal-$name-${fprs[$i]}.asc"); done
    body=$(printf '[%s]\nname=%s (added by decal)\nbaseurl=%s\nenabled=1\ngpgcheck=1\nrepo_gpgcheck=%s\ngpgkey=%s' \
      "$name" "$name" "$dnf" "$rgc" "$(printf 'file://%s\n' "${kps[@]}" | paste -sd' ')")
    if [[ -e $rec && $(cat "$(sys_path "$src")" 2>/dev/null) == "$body" ]]; then return 0; fi
  fi
  step "adding the $name package repository"
  local dl=() k
  for i in "${!urls[@]}"; do
    k=$(ls_fetch "${urls[$i]}") || die "could not download the $name signing key from ${urls[$i]}: nothing added"
    if [[ $LS_DRY_RUN != 1 ]]; then
      if ! have gpg; then pkg_install "repo-$name" gnupg; fi
      [[ $(_key_fpr "$k") == "${fprs[$i]}" ]] \
        || die "the signing key from ${urls[$i]} isn't the one with $name's fingerprint ${fprs[$i]}: nothing added"
      if [[ $PLATFORM != debian ]] && ! grep -qF -- "$_ARMOR" "$k"; then
        die "the signing key from ${urls[$i]} isn't an armored key: nothing added"
      fi
    fi
    dl+=("$k")
  done
  if [[ -e $rec ]]; then _repo_files_rm "$name"; fi   # a changed key list: the old files go first
  if [[ $PLATFORM == debian ]]; then
    local ext=gpg; if [[ $LS_DRY_RUN == 1 ]] || grep -qF -- "$_ARMOR" "${dl[0]}"; then ext=asc; fi
    kps=("/usr/share/keyrings/$name-archive-keyring.$ext"); body=${apt//KEYRING/${kps[0]}}
  fi
  printf '%s\n' "${kps[@]}" "$src" | swrite "$rec"   # the record first: an interrupted add can still be undone
  for i in "${!kps[@]}"; do
    if [[ $LS_DRY_RUN == 1 ]]; then log "[dry-run] write $(sys_path "${kps[$i]}") ($name's signing key)"

  while IFS= read -r p; do if [[ -n $p ]]; then srun rm -f "$(sys_path "$p")"; fi; done < "$rec"
  srun rm -f "$rec"
```

```bash
MODULE_DESC="VPN tools, any of: Tailscale, NetBird, Proton VPN (with their tray icons), WireGuard, OpenVPN, OpenConnect"
MODULE_NEEDS_ROOT=1
# One file per service here, each defining NAME_add, NAME_remove, NAME_status (prints nothing when complete,
# "skipped: …" when it can't apply on this system, else what's missing) and NAME_stamp (succeeds when it's in use).
# Signing in, auth keys and connections are never decal's: you sign in on each machine.

# shellcheck source=/dev/null

_wanted() { local s; for s in "${P_install[@]}"; do if [[ $s == "$1" ]]; then return 0; fi; done; return 1; }
_mark() { rec_has "$REC" "$1" || state_append "$REC" "$1"; }   # before a service's first change: remove can undo it
_take_off() { "$1_remove"; state_drop "$REC" "$1"; }
_join() { local out="" x; for x; do out+="${out:+, }$x"; done; printf '%s' "$out"; }
_os_release() { ( . "$(sys_path /etc/os-release)" 2>/dev/null; eval "printf '%s' \"\${$1:-}\"" ); }   # VAR: decal's own names only

module_add() {
  local s
  for s in "${SERVICES[@]}"; do
    if _wanted "$s"; then "${s}_add"; elif rec_has "$REC" "$s"; then _take_off "$s"; fi
  done
}
module_remove() {
  local i
  for (( i = ${#SERVICES[@]} - 1; i >= 0; i-- )); do
    if rec_has "$REC" "${SERVICES[$i]}"; then _take_off "${SERVICES[$i]}"; fi
  done
  if [[ -e $REC ]]; then srun rm -f "$REC"; fi
}
# remove --only TAG: P_install holds only the services the tag added
MODULE_CAN_DROP=1
module_drop() { local s; for s in "${P_install[@]}"; do if rec_has "$REC" "$s"; then _take_off "$s"; fi; done; }
module_status() {
  local s why ok=() todo=() missing=0
  for s in "${P_install[@]}"; do
    why=$("${s}_status")
    case $why in
      "") ok+=("$s") ;;
      skipped*) ok+=("$s: ${why#skipped: }") ;;
      "not installed") todo+=("$s: not installed"); missing=$(( missing + 1 )) ;;
      *) todo+=("$s: $why") ;;
    esac
  done
  if (( ${#P_install[@]} == 0 || missing == ${#P_install[@]} )); then echo not-installed
  elif (( ${#todo[@]} )); then echo "partial ($(_join "${todo[@]}" "${ok[@]}"))"
  else echo "installed ($(_join "${ok[@]}"))"; fi
}
```

```bash
# system services: enabled by their link (works before a Fedora Atomic reboot too, like docker), started when the unit
# is on the running system; recorded only when decal turned them on, so remove never turns off one you had on
_wants() { sys_path "/etc/systemd/system/multi-user.target.wants/$1"; }
_svc_enabled() { [[ -L $(_wants "$1") || -e $(_wants "$1") ]] || systemctl is-enabled --quiet "$1" 2>/dev/null; }
_svc_on() {
  _svc_enabled "$1" && return 0
  step "turning on $1"
  state_append "$ST/enabled" "$1"
  srun mkdir -p "$(dirname "$(_wants "$1")")"; srun ln -s "/usr/lib/systemd/system/$1" "$(_wants "$1")"
  if [[ -e $(sys_path "/usr/lib/systemd/system/$1") ]]; then
    srun systemctl daemon-reload; srun systemctl start "$1" || warn "$1 didn't start: see systemctl status $1"
  fi
}
_svc_off() {
  rec_has "$ST/enabled" "$1" || return 0
  if [[ -e $(sys_path "/usr/lib/systemd/system/$1") ]]; then srun systemctl stop "$1" 2>/dev/null || true; fi
  srun rm -f "$(_wants "$1")"; srun systemctl daemon-reload 2>/dev/null || true
  state_drop "$ST/enabled" "$1"
}
```

```bash
# it appears (https://repo.protonvpn.com/fedora-N-stable/public_key.asc, its fingerprint checked against Proton's).
declare -gA PV_FEDORA_FPR=(
  [43]=7BB2808996C47DC9EECDA475F7EB64B08C03490D
  [44]=6929133BDE1CE1CFA9EDB286D84176F6844830D4
  [45]=D3AA11B3B1BFB96DF3CA26A2D59CE240EB3EE0B0
)
PV_PKG=proton-vpn-gnome-desktop

_pv_release() { local v; v=$(_os_release VERSION_ID); if [[ $v =~ ^[0-9]+$ && -n ${PV_FEDORA_FPR[$v]:-} ]]; then echo "$v"; fi; }
protonvpn_add() {
  if [[ $PLATFORM == arch ]]; then warn "Proton VPN isn't in Arch's own repositories (only the AUR): skipped"; return 0; fi
  if ! _pkg_present "$PV_PKG"; then
    if [[ $PLATFORM == debian ]]; then
      _mark protonvpn
      repo_add protonvpn-stable --key https://repo.protonvpn.com/debian/public_key.asc "$PV_APT_FPR" \
        --apt "deb [signed-by=KEYRING] https://repo.protonvpn.com/debian stable main"
    else
      local v r keys=(); v=$(_pv_release)
      if [[ -z $v ]]; then
        warn "Proton VPN: this decal doesn't know Proton's signing key for Fedora $(_os_release VERSION_ID) (it knows $(printf '%s\n' "${!PV_FEDORA_FPR[@]}" | sort -n | paste -sd' ')): skipped; a newer decal will"
        return 0
      fi
      _mark protonvpn
      for r in $(printf '%s\n' "${!PV_FEDORA_FPR[@]}" | sort -n); do
        if (( r >= v )); then keys+=(--key "https://repo.protonvpn.com/fedora-$r-stable/public_key.asc" "${PV_FEDORA_FPR[$r]}"); fi
      done
      repo_add protonvpn-stable "${keys[@]}" --dnf 'https://repo.protonvpn.com/fedora-$releasever-stable'
    fi
    if [[ $PLATFORM == fedora-atomic ]]; then
      warn "Proton supports Fedora Workstation; on Fedora Atomic its app is layered, which Proton doesn't officially support"
    fi
    pkg_install vpn-protonvpn "$PV_PKG"
  else
    _mark protonvpn
  fi
  info "Proton VPN is ready: open it from your apps and sign in"
}
protonvpn_remove() { pkg_remove vpn-protonvpn; repo_remove protonvpn-stable; }
protonvpn_status() {
  if [[ $PLATFORM == arch ]]; then echo "skipped: not available on Arch"; return 0; fi
  if ! _pkg_present "$PV_PKG"; then
    if [[ $PLATFORM != debian && -z $(_pv_release) ]]; then echo "skipped: no Proton key for this Fedora release yet"; else echo "not installed"; fi
  fi
}
protonvpn_stamp() { _pkg_present "$PV_PKG"; }
```

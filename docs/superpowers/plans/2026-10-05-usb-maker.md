# USB Maker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `decal usb` (and the menu's usb item) puts a double-clickable decal on a USB stick or in a folder; double-clicking `Decal` on any Linux PC gets decal and the profile and opens the stick menu.

**Architecture:** A tiny static C launcher (`usb/launch.c`, built by the release workflow for x86-64 and aarch64) runs a bash stick script (`usb/start.sh`) that installs decal (online, or from a copy on the stick via a new `install.sh` `DECAL_ARCHIVE` mode), gets the profile (saved read key / sign-in / copy), and opens `decal ui` in stick mode. `lib/usb.py` finds drives and writes sticks safely; `decal usb` (bash) assembles the files; the menu walks through the questions and runs `decal usb` with every answer as an option.

**Tech Stack:** bash, Python 3 standard library, C (musl static), GitHub Actions YAML; decal's bash test harness with stubs.

**Spec:** `docs/superpowers/specs/2026-10-05-usb-maker-design.md` (roadmap: `docs/superpowers/specs/2026-10-04-usb-feature-roadmap.md`)

## Global Constraints

- Root of a stick: only `Decal` (x86-64 launcher). Everything else in `.Decal/`. `Decal-ARM` only with `--arm`, inside `.Decal/`.
- Never touch anything outside `Decal`, `.Decal/` (and, for an upgrade, the hand-made stick's `decal-me`, `Decal/decal-me.sh`, `Decal/decal-token.txt`); never format.
- A saved key is always a fresh read key from `auth.py get REPO --need read` (Decal Profile sign-in or a read-only token page) or `DECAL_STICK_KEY` given explicitly; never `GITHUB_TOKEN`/`GH_TOKEN`/`gh`.
- Writes: `.Decal.new/` then rename swap, `.Decal.old/` removed after; `os.sync()` after.
- decal choices: `newest` (default; online, else the copy, with the message "Couldn't check for a newer decal: using the copy on this stick (VERSION)"), `copy`, `online`.
- How choices: private GitHub `saved-key` (default) | `sign-in` | `copy`; public GitHub `latest` (default) | `copy`; anything else `copy`.
- The stick menu order: Apply everything · Choose what to apply · Preview first · Take it all off · What's on this machine · Use a different profile · Full menu.
- No test touches the network, real drives or `/run/media`; tests stub `gh`, `curl`, `udisksctl`, terminals, and unset `DISPLAY`/`WAYLAND_DISPLAY`.
- Commit messages: one descriptive line in the repo's style, blank line, `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- On exFAT/FAT a `Decal` file and a `Decal/` folder can't coexist (case-insensitive, and the same name anyway): upgrading the hand-made stick must clear `Decal/` before placing the launcher, moving anything unknown in it to `Decal-old/` rather than deleting it. (Task 3: upgrade test with an extra user file in `Decal/`.)
- A key on the stick that was revoked must end with a clear message (or decal's own sign-in), not a bare "not found". (Task 2: start.sh with a failing `decal use` and a saved key.)
- The decal copy must be the running decal's own files (installed or git checkout), with no `.git`, tests or docs, and its `install.sh` must install it. (Task 4: unpack the copy, run its `install.sh` with `DECAL_ARCHIVE`.)
- `decal usb` with no terminal and no `--yes` must stop before writing. (Task 4.)
- A release candidate tag must not become "latest" (the installer would hand it to everyone). (Task 5: `--prerelease` for tags with a `-`.)

- [ ] **Step 3: Write `usb/launch.c`**

```c
/* decal USB stick launcher: double-click it. Runs .Decal/start.sh next to it (that script opens a terminal);
 * from inside .Decal (Decal-ARM), the start.sh next to it. Without one, opens the README.
 * Built static by the release workflow: gcc -Os -static -s (musl). */
#include <libgen.h>
#include <limits.h>
#include <stdio.h>
#include <string.h>
#include <unistd.h>

static int found(char *out, size_t n, const char *dir, const char *name) {
  snprintf(out, n, "%s/.Decal/%s", dir, name);
  if (access(out, R_OK) == 0) return 1;
  snprintf(out, n, "%s/%s", dir, name);   /* the launcher is in .Decal itself */
  return access(out, R_OK) == 0;
}

int main(void) {
  char exe[PATH_MAX], path[PATH_MAX + 32];
  ssize_t n = readlink("/proc/self/exe", exe, sizeof exe - 1);
  if (n < 0) { perror("readlink"); return 1; }
  exe[n] = 0;
  char *dir = dirname(exe);
  if (found(path, sizeof path, dir, "start.sh")) {
    execl("/bin/bash", "bash", path, (char *)0);
    execlp("bash", "bash", path, (char *)0);
    perror("bash");
    return 1;
  }
  if (found(path, sizeof path, dir, "README.txt")) {
    execlp("xdg-open", "xdg-open", path, (char *)0);
    perror("xdg-open");
  }
  return 1;
}
```

- [ ] **Step 4: Write `usb/start.sh`**

```bash
#!/usr/bin/env bash
# decal USB stick: get decal (online, or the copy on this stick), get the profile, open decal's menu. The same on
# every stick; stick.conf next to it says which profile and how. Run by the Decal launcher, or: bash .Decal/start.sh
set -uo pipefail
HERE=$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)
INSTALL_URL=${DECAL_INSTALL_URL:-https://dmacpherson.github.io/decal/install}

# double-clicked: no terminal yet, so open one (sudo prompts and the menu need it)
if [[ ! -t 0 && -z ${DECAL_STICK_IN_TERM:-} ]]; then
  export DECAL_STICK_IN_TERM=1
  for t in ptyxis kgx gnome-terminal konsole xfce4-terminal mate-terminal tilix alacritty kitty x-terminal-emulator xterm; do
    command -v "$t" >/dev/null || continue
    case $t in
      ptyxis|gnome-terminal|kgx|tilix) exec "$t" -- bash "$HERE/start.sh" "$@" ;;
      xfce4-terminal|mate-terminal) exec "$t" -x bash "$HERE/start.sh" "$@" ;;
      *) exec "$t" -e bash "$HERE/start.sh" "$@" ;;
    esac
  done
fi

say() { printf '\033[1;36m==>\033[0m %s\n' "$*"; }
fail() { printf '\033[1;31m%s\033[0m\n' "$*"; read -rp "Press Enter to close… " _ 2>/dev/null || true; exit 1; }
conf() { sed -n "s/^$1=\([^[:space:]#]*\).*/\1/p" "$HERE/stick.conf" | head -1; }

[[ $(uname -s) == Linux ]] || fail "decal only runs on Linux."
[[ -r $HERE/stick.conf ]] || fail "This stick has no stick.conf: run decal usb to set it up again."
PROFILE=$(conf profile); KEY=$(conf key); MODE=$(conf decal); VER=$(conf version)

# 1. decal
online() {
  local s
  if command -v curl >/dev/null; then s=$(curl -fsSL --connect-timeout 10 "$INSTALL_URL") || return 1
  elif command -v wget >/dev/null; then s=$(wget -qO- --timeout=15 "$INSTALL_URL") || return 1
  else return 1; fi
  [[ -n $s ]] && DECAL_NO_MENU=1 bash -c "$s" decal-install
}
from_copy() {   # 0 installed · 2 no copy · fails (exits) when damaged
  local c=$HERE/decal.tar.gz t rc
  [[ -f $c && -f $c.sha256 ]] || return 2
  [[ $(sha256sum "$c" | cut -d' ' -f1) == "$(cut -d' ' -f1 < "$c.sha256")" ]] \
    || fail "The decal copy on this stick is damaged (checksum): run decal usb on your own machine to refresh it."
  t=$(mktemp); tar -xzf "$c" -O decal/install.sh > "$t" 2>/dev/null || { rm -f "$t"; fail "The decal copy on this stick is damaged: run decal usb to refresh it."; }
  DECAL_ARCHIVE=$c DECAL_ARCHIVE_VERSION=${VER:-local} DECAL_NO_MENU=1 bash "$t"; rc=$?; rm -f "$t"; return $rc
}
NO_NET="No internet, and this stick has no copy of decal: connect to the internet and try again."
case $MODE in
  copy) from_copy; rc=$?; (( rc == 0 )) || { (( rc == 2 )) && fail "This stick has no copy of decal: run decal usb to add one."; fail "Couldn't install decal from this stick (see above)."; } ;;
  online) online || fail "$NO_NET" ;;
  *) if ! online; then
       say "Couldn't check for a newer decal: using the copy on this stick (${VER:-unknown version})"
       from_copy; rc=$?; (( rc == 0 )) || { (( rc == 2 )) && fail "$NO_NET"; fail "Couldn't install decal from this stick (see above)."; }
     fi ;;
esac
DECAL=${DECAL_CMD:-$HOME/.local/bin/decal}
[[ -x $DECAL ]] || DECAL=$(command -v decal) || fail "decal didn't install (see the messages above)."
export DECAL_STICK=$HERE

# 2. the profile (on this machine afterwards: unplugging the stick is fine)
case $PROFILE in
  copy)
    t="$(mktemp -d)/stick-profile.tar.gz"
    tar -czf "$t" -C "$HERE/profile" . 2>/dev/null || fail "The profile copy on this stick can't be read: run decal usb to refresh it."
    "$DECAL" --no-update use "$t" || fail "Couldn't use the profile on this stick (see above)." ;;
  *)
    if [[ $KEY == saved ]]; then
      GITHUB_TOKEN=$(tr -d '[:space:]' < "$HERE/key" 2>/dev/null); export GITHUB_TOKEN
      "$DECAL" --no-update use "$PROFILE" \
        || fail "The key on this stick no longer works (revoked or expired): run decal usb on your own machine to give it a new one, or remove .Decal/key to sign in each time."
    else
      "$DECAL" --no-update use "$PROFILE" || fail "Couldn't get $PROFILE (see above)."
    fi ;;
esac

# 3. the menu (stick mode)
exec "$DECAL" --no-update ui
```

(When the key is refused, decal itself already offers part 1's sign-in on the terminal before giving up, so "press s to sign in" from the spec is covered by decal's own prompt; the message above is shown only when that also ends without a profile.)

### Task 3: Drives and writing a stick (`lib/usb.py`)

**Files:**
- Create: `lib/usb.py`
- Create: `tests/test_usb.sh`

**Interfaces:**
- Produces:
  - `drives() -> list[dict]` — keys `device`, `label`, `mount` ("" when unmounted), `size` (bytes), `fstype`, and for mounted ones `ventoy` (bool), `isos` (int), `decal` (has `.Decal/stick.conf`), `old` (hand-made layout). Ventoy first, then by label. Only partitions (or whole disks without partitions) of disks with `tran == "usb"` or `rm`/`hotplug`, with a filesystem in `FS`, not `VTOYEFI`.
  - `mount(device) -> str` — via `udisksctl mount -b DEVICE --no-user-interaction`; the mount point.
  - `read_conf(target) -> dict`.
  - `old_layout(target) -> bool`.
  - `write(target, src) -> str` — `src` holds `Decal` and `.Decal/`; returns `"written"` or `"upgraded"`.
  - CLI: `drives --json`, `mount DEVICE`, `conf TARGET` (JSON), `write TARGET SRC`.
  - Env: `DECAL_LSBLK` (a JSON file used instead of running `lsblk`).

```python
#!/usr/bin/env python3
"""usb.py: USB drives for decal usb, and writing a decal stick safely.

  usb.py drives [--json]     removable/USB filesystems: mounted ones, and ones udisksctl can mount
  usb.py mount DEVICE        mount it (udisksctl, no sudo); prints the mount point
  usb.py conf TARGET         a stick's stick.conf as JSON ({} when there's none)
  usb.py old TARGET          exit 0 when TARGET has the hand-made layout (decal-me, Decal/decal-me.sh)
  usb.py write TARGET SRC    put SRC's Decal and .Decal/ on TARGET: .Decal.new first, then swapped in, so a stick
                             pulled out midway has the old setup or the new one; upgrades the hand-made layout

DECAL_LSBLK: a JSON file used instead of running lsblk (tests)."""
import argparse, glob, json, os, shutil, subprocess, sys

FS = {"vfat", "exfat", "ntfs", "ntfs3", "ext2", "ext3", "ext4", "btrfs", "xfs", "f2fs"}
OLD_FILES = ["decal-me", os.path.join("Decal", "decal-me.sh"), os.path.join("Decal", "decal-token.txt"),
             os.path.join("Decal", "decal-me.desktop")]


def lsblk():
    f = os.environ.get("DECAL_LSBLK")
    if f:
        return json.load(open(f))
    r = subprocess.run(["lsblk", "-J", "-b", "-o", "NAME,PATH,LABEL,MOUNTPOINT,RM,HOTPLUG,TRAN,SIZE,FSTYPE,TYPE"],
                       capture_output=True, text=True)
    return json.loads(r.stdout or '{"blockdevices": []}')


def old_layout(t):
    return os.path.exists(os.path.join(t, "decal-me")) and os.path.exists(os.path.join(t, "Decal", "decal-me.sh"))


def drives():
    out = []
    for disk in lsblk().get("blockdevices", []):
        if disk.get("type") != "disk" or not (disk.get("tran") == "usb" or disk.get("rm") or disk.get("hotplug")):
            continue
        for part in disk.get("children") or [disk]:
            if part.get("fstype") not in FS or part.get("label") == "VTOYEFI":
                continue
            mp = part.get("mountpoint") or ""
            d = {"device": part["path"], "label": part.get("label") or os.path.basename(mp) or part["name"],
                 "mount": mp, "size": int(part.get("size") or 0), "fstype": part["fstype"]}
            if mp:
                d.update(ventoy=d["label"] == "Ventoy" or os.path.isdir(os.path.join(mp, "ventoy")),
                         isos=len(glob.glob(os.path.join(mp, "*.iso"))),
                         decal=os.path.exists(os.path.join(mp, ".Decal", "stick.conf")), old=old_layout(mp))
            out.append(d)
    out.sort(key=lambda d: (not d.get("ventoy"), d["label"].lower()))
    return out


def mount(device):
    r = subprocess.run(["udisksctl", "mount", "-b", device, "--no-user-interaction"], capture_output=True, text=True)
    if r.returncode != 0 or " at " not in r.stdout:
        sys.exit(f"error: couldn't mount {device}: {(r.stderr or r.stdout).strip()}")
    return r.stdout.strip().split(" at ", 1)[1].rstrip(".")


def read_conf(t):
    out = {}
    try:
        for line in open(os.path.join(t, ".Decal", "stick.conf")):
            line = line.split("#", 1)[0].strip()
            if "=" in line:
                k, v = line.split("=", 1)
                out[k.strip()] = v.strip()
    except OSError:
        pass
    return out


def _copytree(src, dst):   # FAT/exFAT keep no modes or owners: plain copies
    shutil.copytree(src, dst, copy_function=shutil.copyfile)


def write(target, src):
    os.makedirs(target, exist_ok=True)
    new, cur, old = (os.path.join(target, n) for n in (".Decal.new", ".Decal", ".Decal.old"))
    for p in (new, old):
        shutil.rmtree(p, ignore_errors=True)
    _copytree(os.path.join(src, ".Decal"), new)
    os.sync()
    if os.environ.get("DECAL_USB_FAIL_AFTER_NEW"):   # tests: a stick pulled out here
        sys.exit("error: interrupted")
    if os.path.exists(cur):
        os.rename(cur, old)
    os.rename(new, cur)
    os.sync()
    shutil.rmtree(old, ignore_errors=True)
    how = "written"
    if old_layout(target):   # the hand-made stick: its files go only now the new setup is in place
        for f in OLD_FILES:
            try:
                os.remove(os.path.join(target, f))
            except FileNotFoundError:
                pass
        how = "upgraded"
    d = os.path.join(target, "Decal")
    if os.path.isdir(d):   # a Decal folder can't share the launcher's name (FAT/exFAT ignore case, too)
        if os.listdir(d):
            os.rename(d, os.path.join(target, "Decal-old"))
        else:
            os.rmdir(d)
    tmp = os.path.join(target, "Decal.new")
    shutil.copyfile(os.path.join(src, "Decal"), tmp)
    try:
        os.chmod(tmp, 0o755)
    except OSError:
        pass
    os.replace(tmp, d)
    os.sync()
    return how


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("cmd", choices=["drives", "mount", "conf", "old", "write"])
    ap.add_argument("args", nargs="*")
    ap.add_argument("--json", action="store_true")
    a = ap.parse_args()
    if a.cmd == "drives":
        ds = drives()
        print(json.dumps(ds) if a.json else "\n".join(f"{d['device']}\t{d['label']}\t{d['mount']}" for d in ds))
    elif a.cmd == "mount":
        print(mount(a.args[0]))
    elif a.cmd == "conf":
        print(json.dumps(read_conf(a.args[0])))
    elif a.cmd == "old":
        sys.exit(0 if old_layout(a.args[0]) else 1)
    else:
        print(write(a.args[0], a.args[1]))


if __name__ == "__main__":
    main()
```

def public(source):
    """True when a github: repo answers without a key (a public repo); False when private, missing or offline."""
    m = re.fullmatch(rf"github:({OWNER}/{NAME})(@\S+)?", source)
    if not m:
        return False
    api = os.environ.get("DECAL_GITHUB_API", "https://api.github.com").rstrip("/")

        with urllib.request.urlopen(urllib.request.Request(api + "/repos/" + m.group(1),
                                    headers={"Accept": "application/vnd.github+json"}), timeout=15) as r:
            return r.status == 200
    except (urllib.error.URLError, OSError, ValueError):
        return False

# usb_bin : a folder with the launchers (Decal-x86_64, Decal-aarch64): the release's usb/bin, else downloaded once
usb_bin() {
  local d=${DECAL_USB_BIN:-$LS_REPO/usb/bin} c="${XDG_CACHE_HOME:-$HOME/.cache}/decal/usb-bin" t
  if [[ -f $d/Decal-x86_64 ]]; then echo "$d"; return 0; fi
  if [[ -f $c/Decal-x86_64 ]]; then echo "$c"; return 0; fi
  info "getting the stick launchers (this copy of decal doesn't have them)"
  t=$(mktemp -d "$LS_RUNTMP/rel.XXXXXX")
  curl -fsSL https://github.com/dmacpherson/decal/releases/latest/download/decal.tar.gz -o "$t/d.tgz" \
    && curl -fsSL https://github.com/dmacpherson/decal/releases/latest/download/decal.tar.gz.sha256 -o "$t/sum" \
    || die "couldn't download the stick launchers"
  [[ $(sha256sum "$t/d.tgz" | cut -d' ' -f1) == "$(cut -d' ' -f1 < "$t/sum")" ]] || die "the launchers download is damaged"
  tar -xzf "$t/d.tgz" -C "$t" decal/usb/bin 2>/dev/null || die "the latest release has no stick launchers yet"
  mkdir -p "$c"; cp "$t/decal/usb/bin/"* "$c/"; echo "$c"
}

  if [[ $kind == github ]]; then
    if [[ -z $how ]]; then if python3 "$LS_REPO/lib/source.py" public "$src"; then how=latest; else how=saved-key; fi; fi
  else

    fi
  fi

  files="$LS_RUNTMP/stick"; rm -rf "$files"; mkdir -p "$files/.Decal"

    copy) mkdir -p "$files/.Decal/profile"; cp -a "$STAGE_DIR/." "$files/.Decal/profile/"
          rm -rf "$files/.Decal/profile/.git" "$files/.Decal/profile/.decal-source"; : > "$files/.Decal/profile/.decal-stamp"
          how_text="a copy of $src" ;;
    saved-key) ( umask 077; printf '%s\n' "$key" > "$files/.Decal/key" ); how_text="$src (with a read-only key)" ;;
    sign-in) how_text="$src (signs in each time)" ;;
    latest) how_text="$src (public: always the latest)" ;;
  esac
  if [[ $dmode != online ]]; then   # this decal's own files (installed or a checkout), without .git, tests or docs
    tar -czf "$files/.Decal/decal.tar.gz" -C "$(dirname "$LS_REPO")" --exclude=.git --exclude=tests --exclude=docs \
      --exclude=__pycache__ --exclude=.superpowers --transform "s,^$(basename "$LS_REPO"),decal," "$(basename "$LS_REPO")"
    (cd "$files/.Decal" && sha256sum decal.tar.gz > decal.tar.gz.sha256)
  fi
  { echo "# Made by decal $ver on $(date +%F). Run decal usb to change it."

```yaml
# Push a tag like v1.2.0 -> a GitHub release with decal.tar.gz and its checksum (what install.sh downloads), with the
# USB stick launchers built static for x86-64 and aarch64 inside it (usb/bin). A tag with a "-" (v1.2.0-rc1) is a
# pre-release: never "latest". Run the checks first (bash tests/run.sh, shellcheck, gitleaks); this only packages.
name: release
on:
  push:
    tags: ["v*"]
permissions:
  contents: write
jobs:
  launchers:
    strategy:
      matrix:
        include:
          - { runner: ubuntu-latest, arch: x86_64 }
          - { runner: ubuntu-24.04-arm, arch: aarch64 }
    runs-on: ${{ matrix.runner }}
    steps:
      - uses: actions/checkout@v4
      - name: Build (static, musl)
        run: |
          docker run --rm -v "$PWD:/w" -w /w alpine:3 sh -c \
            'apk add -q gcc musl-dev && gcc -Os -static -s -o Decal-${{ matrix.arch }} usb/launch.c'
          file Decal-${{ matrix.arch }} | tee /dev/stderr | grep -q 'statically linked\|static-pie linked'
      - uses: actions/upload-artifact@v4
        with:
          name: launcher-${{ matrix.arch }}
          path: Decal-${{ matrix.arch }}
  release:
    needs: launchers
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/download-artifact@v4
        with:
          path: bin
          merge-multiple: true
      - name: Package
        run: |
          mkdir dist stage
          git archive --format=tar --prefix=decal/ "$GITHUB_REF_NAME" | tar -x -C stage   # .gitattributes leaves tests out
          mkdir -p stage/decal/usb/bin && cp bin/Decal-* stage/decal/usb/bin/ && chmod 755 stage/decal/usb/bin/*
          tar -czf dist/decal.tar.gz -C stage decal
          (cd dist && sha256sum decal.tar.gz > decal.tar.gz.sha256)
          tar -tzf dist/decal.tar.gz decal/decal decal/install.sh decal/usb/bin/Decal-x86_64 decal/usb/bin/Decal-aarch64 >/dev/null
      - name: Publish
        env:
          GH_TOKEN: ${{ github.token }}
        run: |
          pre=(); if [[ $GITHUB_REF_NAME == *-* ]]; then pre=(--prerelease); fi
          gh release create "$GITHUB_REF_NAME" dist/decal.tar.gz dist/decal.tar.gz.sha256 --title "$GITHUB_REF_NAME" --generate-notes "${pre[@]}"
```
